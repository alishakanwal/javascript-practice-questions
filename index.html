01

Arrays

Store, access and manage multiple values.

QUESTION 01

Create an array of five numbers and print all elements.

let numbers = [10, 20, 30, 40, 50];
console.log(numbers[0]);
console.log(numbers[1]);
console.log(numbers[2]);
console.log(numbers[3]);
console.log(numbers[4]);

How it works

An array stores multiple values in one variable. Each element has an index starting from 0. We use the index to print each number.

Output

10
20 
30
40
50

QUESTION 02

Create an array of three fruits and print the first and last elements.

let fruits = ["apple", "banana", "mango"];

console.log(fruits[0]);
console.log(fruits[2]);

How it works

The first fruit is at index 0, while the last fruit is at index 2. We access both using their indexes.

Output

apple
mango

QUESTION 03

Add "Mango" to the end of an array using push().

let fruits = ["apple", "banana"];
fruits.push("Mango");
console.log(fruits);

How it works

The push() method adds a new element to the end of an existing array.

Output

["apple", "banana", "Mango"]

QUESTION 04

Find the length of an array.

let numberList = [10, 20, 30, 40, 50];
console.log(numberList.length);

How it works

The length property returns the total number of elements in an array.

Output

5
02

Functions

Reusable code that performs a task.

QUESTION 05

Write a function that prints "Hello World".

function greet() {
    console.log("Hello World");
}
greet();

How it works

The function contains the code to print the message. Calling greet() runs the function.

Output

Hello World

QUESTION 06

Write a function that takes two numbers and prints their sum.

function add(a, b) {
    console.log(a + b);
}
add(10, 20);

How it works

The parameters a and b receive the two numbers. The plus operator adds them together.

Output

30

QUESTION 07

Write a function that takes a number and returns its square.

function square(number) {
    return number * number;
}
console.log(square(5));

How it works

A number's square is the number multiplied by itself. return sends the calculated result back to the caller.

Output

25

QUESTION 08

Write a function that checks whether a number is even or odd.

function checkNumber(num) {
    if (num % 2 === 0) {
        console.log("Even");
    } else {
        console.log("Odd");
    }
}

checkNumber(6);

How it works

The remainder operator % checks the remainder after division by 2. A remainder of 0 means even; otherwise, the number is odd.

Output

Even

QUESTION 09

Write a function to find the largest of two numbers.

function findLargest(a, b) {
    if (a > b) {
        console.log(a);
    } else {
        console.log(b);
    }
}
findLargest(15, 10);

How it works

The if condition compares both numbers. The larger number is printed.

Output

15

QUESTION 10

Write a function that takes a name and prints a welcome message.

function welcome(name) {
    console.log("Welcome " + name);
}
welcome("Ali");

How it works

The name parameter receives "Ali". The plus operator joins the welcome message and name.

Output

Welcome Ali
03

Objects

Organize related information using properties.

QUESTION 11

Create a student object and print all three properties.

let student = {
    name: "Ali",
    age: 18,
    class: "12th"
};
console.log(student.name);
console.log(student.age);
console.log(student.class);

How it works

The object stores the student's name, age and class. Dot notation accesses each property.

Output

Ali
18
12th

QUESTION 12

Create a car object and print its brand.

let car = {
    brand: "Toyota",
    model: "Corolla",
    color: "Black"
};
console.log(car.brand);

How it works

The car object stores three properties. car.brand accesses and prints the brand value.

Output

Toyota

QUESTION 13

Update the student's age to 20 and print it.

let student2 = {
    name: "Ali",
    age: 18
};
student2.age = 20;
console.log(student2.age);

How it works

Assigning 20 to student2.age updates the existing age property. The updated value is then printed.

Output

20

QUESTION 14

Create a student object with name and marks. Print both using a function.

let student3 = {
    name: "Ali",
    marks: 85
};
function printStudent() {
    console.log(student3.name);
    console.log(student3.marks);
}
printStudent();

How it works

The object stores the student's name and marks. The function accesses and prints both properties when it is called.

Output

Ali
85

How to Check the Result

Follow these steps to check the output of the JavaScript programs:

01

Open the JavaScript File

Open the JavaScript file in your code editor and make sure the code is saved.

02

Open the HTML Page

Open the HTML file in Google Chrome or another web browser.

03

Open Developer Tools

Right-click on the webpage and select Inspect.

04

Go to the Console

Click the Console tab in Developer Tools to view the JavaScript output.

05

Check the Output

Run the JavaScript program and check the result displayed in the Console.

Note: If the program uses prompt(), enter the requested value when the popup appears. The result will be displayed in the Console.
